# Product Requirements — Our Christmas Story MVP

## Positioning

**Digital Gifter** · “Some people deserve more than an ordinary gift.”

Primary SKU: **Our Christmas Story · $57**

Not an AI PDF bundle. Not a greeting-card marketplace. A premium emotional gift: song + memory film + private interactive page + surprise + printable QR card.

## Buyer journey

1. Landing + demo proof  
2. Three questions → personalized preview (example song labeled)  
3. Optional enrichment (memories, photos, dedication)  
4. Offer + guest checkout (disabled until authorized)  
5. Production → buyer review → approve → send / schedule / print QR  

## Recipient journey

Welcome → unwrap → from → dedication → story → song → film → surprise → final → keepsakes → optional reaction → subtle gift-back link after the experience.

No prices, ads, or invoices on the gift page.

## Out of scope for MVP

- Live Stripe charges  
- Suno automated commercial generation  
- 24-day Advent dependency  
- Christmas Planner / recipe / AI credits bundling as primary offer  
- Real customer email sends  

## Feature flags

Add-ons (`+$17` / `+$12` / `+$12`) defined but `enabled: false`.
