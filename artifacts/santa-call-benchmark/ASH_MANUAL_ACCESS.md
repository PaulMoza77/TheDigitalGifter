# Santa Call — ash voice manual access

## Configured
- Voice: **ash** (Contabo + code default)
- Model: `gpt-realtime`
- LIVE products: empty (not commercial)

## Open on iPhone / Safari
1. On this Mac, open the QR: `/tmp/tdg-santa-qa-call-qr.png`
2. Or run: `cat /tmp/tdg-santa-qa-call-url` and AirDrop / Messages the link to yourself
3. Safari → Allow Microphone
4. Tap **Începe apelul**
5. Confirm Romanian greeting uses child name **Andrei**, voice sounds like **ash**
6. Try interrupt while Santa speaks
7. Optionally switch languages mid-call (EN / DE / …) then back to RO
8. Stay until auto-end (~3 min) or hang up

Token files are mode 600 under `/tmp` — do not paste into chat/git.
